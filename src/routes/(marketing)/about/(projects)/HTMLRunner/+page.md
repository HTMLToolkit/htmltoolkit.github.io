HTMLRunner is an editor for HTML, CSS, and JavaScript that runs in the browser and shows the result as you type.

## Features

- CodeMirror 6 editors with syntax highlighting, linting, auto-indent, and bracket matching.
- Live preview with an auto-run mode and a manual Run button.
- Console with log, error, warn, and info filters, object inspection, stack traces, and timestamps.
- Formatting with Prettier.
- Export the project as a ZIP, or copy the editors and console output.
- Dark and light mode, tabs, persistent state, and keyboard shortcuts.

There is no install and no server. The editor is a static page.
