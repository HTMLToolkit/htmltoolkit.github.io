HTMLChat is a browser chat client with a small edge backend instead of a traditional server.

- Rooms for general, random, offtopic, and computers chat.
- Nicknames with color coding.
- File uploads with previews, replies, and message search.
- Moderator tools for delete and ban.
- Settings for desktop notifications and sounds.
- Export chat logs as JSON.

It is an experiment, so expect some rough edges. Messages are polled for now. WebSockets are on the roadmap.
