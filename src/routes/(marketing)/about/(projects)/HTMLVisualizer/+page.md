HTMLVisualizer turns an HTML document into an interactive graph so you can see how its parts connect.

## Features

- Upload an HTML file to build a structure map.
- Interactive graph with zoom, pan, and draggable nodes.
- Links inline styles, stylesheet rules, and script-driven style changes to the elements they affect.
- Pulls out functions, variables, and function calls from scripts.
- Click a node to read its code in a side view. Every other connection dims so the selected node stands out.
- Details panel for the selected node.
- Works offline and installs as a PWA.

The repo and README still use the older name HTMLNodeMapper in places.
