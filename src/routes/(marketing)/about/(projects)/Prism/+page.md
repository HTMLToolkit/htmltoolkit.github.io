Prism is a small viewer and creator for CSS gradients.

- Edit a gradient and see it as the page background right away.
- Five presets to start from: Sunset, Ocean, Gold, Sky, and Purple.
- Add or remove color stops, with a minimum of two.
- Paste a CSS gradient string, or copy the one you built.
- Text switches between black and white based on the gradient brightness.
- Installs as a PWA.
