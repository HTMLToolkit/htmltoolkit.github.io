HTMLEditor is a drag-and-drop editor for building and prototyping page layouts in the browser.

## Features

- Drag elements onto the canvas: divs, text, images, buttons, forms, flexbox, grids, and cards.
- Live preview in an iframe while you edit.
- HTML, CSS, and JavaScript tabs with syntax highlighting.
- Properties panel for position, size, colors, and content.
- Snap guides to line elements up.
- Undo and redo, with Ctrl+Z and Ctrl+Y.
- Dark mode, toggled with Ctrl+D.
- Save and load projects, or export them as HTML, CSS, and JS files.
- Auto-save every 30 seconds.
- Keyboard shortcuts, including Ctrl+S to save and ? for the shortcuts panel.
