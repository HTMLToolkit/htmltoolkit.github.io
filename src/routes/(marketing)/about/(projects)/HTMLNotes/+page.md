HTMLNotes is a small note-taking app that runs in the browser.

- Write notes in Markdown with a live preview.
- Create, view, and delete notes from a toggleable sidebar.
- Import and export notes as JSON or Markdown.
- Notes save as you type.
- Runs as a PWA for offline use.

Markdown editing and icons use TinyMDE and Font Awesome.
